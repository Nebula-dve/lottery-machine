# 好运摇号机

一个无需构建步骤的中文单页摇号机。直接打开 `index.html` 即可使用。

## 功能

- **超级大乐透**：前区 01–35 摇出 5 个号码，后区 01–12 摇出 2 个号码。
- **双色球**：红球 01–33 摇出 6 个号码，蓝球 01–16 摇出 1 个号码。
- 逐球揭晓动画、最近 20 组本机记录和移动端布局。
- 号码由浏览器随机数生成，优先使用 `crypto.getRandomValues`（含拒绝采样，无取模偏差）；不可用时自动回退到普通随机数并提示。
- 记录仅保存在当前浏览器的本地存储中。

> 早期版本中的「自定义演示（6 蓝 + 1 红）」已修正为符合官方规则的双色球；旧的本地记录仍会以「自定义演示」标签正常显示。

本项目仅用于娱乐与活动抽奖，不属于官方彩票发行或开奖系统。
